Case study · Encrypted Messaging

Crypho: secure messaging, redesigned

Crypho provides real-time, end-to-end encrypted communication across web, mobile and desktop, with clients including the Norwegian National Security Authority, Oslo Police and Telemark Hospital. The tool needed to stay both secure and easy to use while catching up with a market that had moved on.

Role
Research, design, front-end development
Platforms
Web, desktop, mobile
Notable clients
NSM, Oslo Police, Telemark Hospital
My contribution
Research, design, front-end, testing
Link to Crypho page

Background

Missing functionality and dated look

Crypho was functional but had become dated in both design and functionality. User feedback pointed at navigation, aesthetics and a missing set of features that would improve day-to-day workflow, while the competitive landscape for messaging tools had moved considerably since the app's original release.

Challenges

Three specific problems

  • Usability issues: navigation challenges were a direct source of user frustration.
  • Missing functionality: users couldn't easily manage, filter or search within their conversations.
  • Outdated visual design: the interface needed a more modern look.

Approach

Research, restructure, redesign, extend

Work started with an in-depth analysis of user feedback to identify real pain points. Navigation was restructured to simplify how people accessed and moved through their messages. The interface itself was redesigned for a more contemporary, visually coherent feel. And a set of new features shipped alongside it: message expiration and deletion, a message view list, conversation filtering, search, and secure identification.

My part covered research and design across both existing layouts and new feature work, with a front-end focus during implementation, improving existing elements, building new ones, and testing for functionality and stability as the product shipped.

Constraints

Security dictated how far the redesign could go

To maintain the encryption and file-sharing guarantees the client base depended on, not every process could be streamlined or every feature added. Some usability trade-offs stayed in place because the alternative would have weakened the security model the product exists for.
